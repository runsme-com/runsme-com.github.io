# Open source Lab

判断一款产品是否具备价值，并不取决于能否实现技术开发，核心在于三个问题：它在解决谁的痛点、满足了哪些真实需求、商业模式是否成立。

如今落地执行的成本正在不断降低，好的创意、独特的思考视角、一个值得被解决的真实问题，反而变成最稀缺的资源。

想要做成一件长期项目，通常需要四项基础特质：

1. 发自内心的热情与驱动力
2. 面对挫折能够坚持下去的韧性
3. 完成项目所必备的专业能力
4. 敢于试错，并且能够理性评估启动阶段的风险敞口

外部大环境往往难以人为改变。我们可以通过持续阅读、动手编码、观察市场变化，培养自己识别真实需求的能力。在发展不顺的时候沉下心积累，机会到来时才有能力及时把握住。

不必一味透支自身去强行内卷。很多取得成就的人依托于上一代人打下的基础。我们很难直接复刻他人的路径，更现实的目标，是在自己所在的领域深耕沉淀，为后来者搭建台阶、创造有利条件。

## 长期做事的底层认知

快即是慢，慢即是快。事业的成长往往需要在实践中不断试错、沉淀，前期投入的学习、实操、验证时间，会长期影响之后的决策与行动。

一份事业通常以五年作为一个成长周期，几乎不存在真正速成的项目。短期炒作式的项目，周期短、随机性强、投机属性重。频繁更换方向会带来高昂的磨损成本，它的代价远高于短期的机会损失。

做事需要选定一个真实问题，稳步推进，在可控的风险范围内创造收益。盲目跟风别人设计好的套路，很容易陷入被动。

财富需要长期积累，急于求成反而更容易亏损。
优先选择脚踏实地、自己真正热爱并且愿意长期投入的方向。
