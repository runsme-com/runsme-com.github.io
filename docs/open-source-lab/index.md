# Open source Lab

真正决定一个产品有没有价值的，不是你能不能把它做出来，而是你有没有想清楚：它解决谁的问题？满足什么需求？有没有成立的商业模式？
当执行越来越便宜，最珍贵的反而是一个好的创意、一个新的思维角度，和一个真正值得被解决的问题。

1. 内心渴望；
2. 顽强毅力；
3. 专业技术；
4. 勇于尝试（尝试真的需要勇敢和风险敞口计算，尤其是开始启动的时候）

大环境我们无力改变，只能多读书，多编码，多观察市场，观察需求，无边黑暗时抵御岁月漫长，光明乍现时抓住的能力也多一些。

有些时候我们不要过于牺牲自己去刻苦，家庭出身背景很重要，那些名人大多站在他们父辈的肩膀上，我们成为不了他们，我们只能成为他们父辈那样的人，去在一个新的领域/新的权力机关去托举。这个就是一种设定。

快就是慢，慢就是快，人生很长，每一个 事业的建立都是 在泥里摸爬，沉淀和产出的，这段时间学习、实践与验证投入的精力与时间，都会在未来影响你的行为，这就是目标函数的延续，而一个事业的开始到成长是以5年为一个周期的，没有一个事业是速成的，即使是炒作也是三个月的买入，三个月的拉升与清仓，时间太短，随机性和投机性太长，你的机会成本越小，同时你的磨损成本越大，而磨损成本是巨大的，机会成本在频繁发生的模式成本面前很小，我们要认真的去做一件事，去解决一个问题，去发现一个漏洞，去赚能接受的风险敞口的钱，否则别人做局你，
你必然是死亡。

钱需慢慢赚，心急则钱散

踏实做事，做实事。做喜欢热爱的事情。
