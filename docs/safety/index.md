# 安全策略

当公司使用开源软件项目时，他们需要了解许可和合规情况，检查项目的健康状况，确保没有安全漏洞，并且在某些情况下，还要识别有才华的社区成员，以便进行潜在的招聘流程

当公司参与开源软件项目时，他们需要确保没有知识产权（IP）问题，确保公司贡献的影响力和项目领导地位，有时还要帮助有才华的人通过贡献保持与公司的互动。

当公司发布和维护开源项目时，他们负责确保社区参与和发展，检查没有知识产权问题，保持公司影响力和领导地位，甚至可能吸引新人才。

## 系统和策略由数据驱动

没有数据，你只是一个有观点的人。

拥有自己的观点本身并不是坏事，但基于数据的意见无疑会让你更容易理解、讨论并确定最适合公司及其目标的流程。

## 目的与策略

发布开源软件项目时的目标之一是壮大围绕它们的社区。衡量公司如何从外部处理项目贡献，有助于理解其“欢迎”程度，并识别导师（或瓶颈）及降低贡献门槛的机会。

## 获取开源软件并贡献

当一个组织吸纳和培养的了大量科学家、计量经济学家、数据分析师、数学家、KOL，这个组织将从一个私立组织转变成为社会机构，对人类、社会做出贡献，通过开源组织进行团队贡献就成为了一个可行性的通道。

一个好的策略和结果是将公司从纯粹的开源软件用户转变为其开源系统入站项目的贡献者。从提交问题和提问帮助解决问题，到回答问题，提交 PR，发送补丁，贡献帮助项目发展和维护，同时回馈社区。这不会立刻发生，但随着时间推移，公司将被视为开源软件生态系统的公民。最终，公司里的一些人也可能参与维护这些项目。

最后但同样重要的是，公司需要避免“全能症幻想”综合症。对于一些开源软件项目，可能对公司提供咨询、定制、维护和或支持服务。与其用开源软件，花时间和人力自建、自我开发或试图将这些服务引入内部，不如雇佣相关公司来做思考工作，这样可能更聪明、更高效。 同时欢迎有需求的团队/组织/公司对我公司 市场部进行交流与合作的提出，通过此邮箱： contact@runsme.com；如果是开源相关内容请通过此邮箱：opensource@runsme.com
